改进连接恢复和失败提示。

- 无线连接进入暂时等待状态时，保留连接至本次请求的超时期限，给网络恢复留出时间。
- 修复连接失败后重试过于频繁的问题；重新配对、粘贴连接信息或重新启用设备时会立即重试。
- 区分局域网访问权限不足、手机地址不可达和配对握手失败，便于定位连接问题。
- USB 连接提示改为「USB 已连接，暂时无法连接手机 App。请打开手机 App，工具会自动重试」。
- 简化重复的连接方式描述，将 Xcode 断点检查移入「连接帮助」。

手机 App 从后台回到前台后的 USB 监听恢复，需要手机端安装包含对应修复的版本；仅更新 Mac 应用不会更新手机端。

下载 `Tracking-Inspector-1.1.1-arm64.dmg`，将应用拖入 `Applications` 即可安装。支持 macOS 13+，仅限 Apple Silicon（M 系列芯片）。
