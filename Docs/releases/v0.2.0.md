支持同时查看多台 iOS Debug 设备的埋点。

- 在左侧勾选设备，最多同时连接 8 台；USB、Wi-Fi 可混合使用。
- 合并事件流标注每条事件的来源，可按设备、事件、页面和动作筛选。
- 每台设备独立读取、配对、重连和管理会话，一台设备停在断点不会阻塞其他设备。
- 清空当前设备或全部设备；JSON 导出包含设备和会话信息。
- 新增 DMG 安装包，支持 Apple Silicon 和 Intel。
- 移除应用内的模拟设备与演示数据，只展示实际连接的采集端。

下载 `Tracking-Inspector-0.2.0-universal.dmg`，打开后将 `Tracking Inspector.app` 拖入 `Applications`。运行需要 macOS 13 或更高版本，无需 Python、Node.js 或 Homebrew。iOS Debug App 需要接入采集协议；无线需在同一局域网开启采集并配对。

此版本采用 ad-hoc 签名，尚未经过 Developer ID 签名与 Apple 公证。其他 Mac 下载后可能被 Gatekeeper 拦截；这是开发工具的当前分发限制。`SHA256SUMS` 提供安装包校验值。
