Tracking Inspector 首个正式版本：在 Mac 上查看和分析 iOS Debug 埋点。

- USB、局域网自动发现及粘贴连接信息配对，最多同时查看 8 台设备。
- 同一设备自动合并连接；USB 优先，已配对的局域网连接可在拔线后接续。
- 参数搜索、事件筛选、一键只看或排除，以及保存常用筛选。
- 两条事件字段对比，从参数创建校验规则，保存前预览异常。
- 保存调试记录并离线回看，数据保留在本机。

下载 `Tracking-Inspector-1.0.0-universal.dmg`，将应用拖入 `Applications` 即可安装。支持 macOS 13+、Apple Silicon 和 Intel；运行无需 Python、Node.js 或开发环境。iOS App 需要接入采集协议。

当前使用 ad-hoc 签名，尚未经过 Developer ID 签名与 Apple 公证，首次打开可能被系统拦截。附带 `SHA256SUMS` 校验文件。
