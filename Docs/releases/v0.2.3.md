# Tracking Inspector v0.2.3

- 新增「粘贴并连接」：在手机复制完整连接信息后，Mac 一次粘贴即可填写地址并配对，无需分两次输入。
- 原「手动连接」入口更名为「连接设备」，旧版采集端可继续展开手动填写地址和配对码。
- 校验连接信息版本、长度、地址和密钥；错误提示不回显剪贴板中的配对码。只在用户点击粘贴按钮时读取剪贴板。

此功能需要采集端提供「复制连接信息」，格式见采集协议。地址保存在本机，配对码仍只保存在进程内存；手机重新开启无线或 Mac 退出后需要重新配对。

已通过 Swift Testing、Web 测试和通用版构建。DMG 支持 Apple Silicon 和 Intel；当前使用 ad-hoc 签名，尚未进行 Developer ID 签名与 Apple 公证。
