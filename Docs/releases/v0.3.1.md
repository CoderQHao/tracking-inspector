这次重做了事件筛选和校验规则的操作流程：

- 事件行与详情可以一键「只看」或「排除」。当前条件直接显示在列表上方，支持逐项移除、撤销与重置。
- 「事件筛选」按名称搜索事件类型、查看数量，并恢复已排除的事件。
- 保存筛选前显示条件摘要；再次修改会提示「已修改」，点击「更新此筛选」即可保存。
- 参数旁点击「校验」，自动带入事件、字段和样本值。保存前显示匹配、通过、异常数量及原因。
- 允许值改为点选样本或逐项输入，无需填写 JSON；类型和允许值检查可同时要求字段存在。
- 增加「字段不能为空」，与只检查存在的旧版必填语义分开。已有筛选和规则继续保留。

支持 macOS 13+，DMG 同时包含 Apple Silicon 和 Intel。运行无需 Python、Node.js 或开发环境；正式应用没有内置模拟数据。

此版本仍使用 ad-hoc 签名，未增加自动更新、Developer ID 签名或 Apple 公证。提供 SHA256SUMS 供核验下载。
