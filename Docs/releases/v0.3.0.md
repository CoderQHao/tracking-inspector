本版加入五项日常调试能力：

- 同一设备的 USB、Bonjour、手动连接在验证身份后自动合并，优先 USB，可切换至已配对的局域网，保持事件去重和读取进度。
- 选定对比基准，查看另一条事件新增、缺失及变化的字段。
- 隐藏同名噪声事件，保存、应用、覆盖或删除筛选预设。
- 保存当前记录或筛选结果，重新打开 JSON 回看；兼容旧版 v2 导出。
- 自定义必填、类型、允许值和重复触发规则，在事件详情查看原因或只看异常。

支持 macOS 13+，DMG 同时包含 Apple Silicon 和 Intel。无需 Python、Node.js 或开发环境；没有内置模拟数据。

设备合并需要先成功连接各入口。新采集端的匿名 deviceID 支持跨启动识别；旧采集端在同次 App 会话内合并。备用无线入口仍需配对。回看记录时实时采集继续，容量限制保持 2,000 条 / 16 MiB；保存的是当前保留的快照。

此版本仍使用 ad-hoc 签名，未增加自动更新、Developer ID 签名或 Apple 公证。提供 SHA256SUMS 供核验下载。
