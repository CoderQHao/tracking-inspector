新增菜单栏常驻与后台采集，并改进实时事件的浏览体验。

- 菜单栏可查看设备连接状态、打开观察台、连接设备和刷新 USB 设备。
- 关闭主窗口后继续采集，重新打开可恢复当前保留的记录；暂停更新只冻结页面显示。
- 记录由应用统一管理，最多保留 2,000 条 / 16 MB，避免窗口重建丢失记录。
- 修复实时刷新期间「暂停滚动更新」「清空全部」偶发点击无响应的问题。
- 去掉页面最大宽度限制，减少 4K 等大屏两侧留白。
- 最新接收的事件显示在顶部，「查看最新」直接回到顶部；新事件插入时保持旧事件的阅读位置。

下载 `Tracking-Inspector-1.1.0-arm64.dmg`，将应用拖入 `Applications` 即可安装。支持 macOS 13+，仅限 Apple Silicon（M 系列芯片）。

记录只保留在本次运行的内存中，需要留存时请在退出前保存。当前沿用 ad-hoc 签名，尚未经过 Developer ID 签名与 Apple 公证；Release 附带 `SHA256SUMS` 校验文件。
