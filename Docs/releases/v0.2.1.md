为 Tracking Inspector 增加应用图标和界面预览。

- 新增青绿色应用图标，覆盖 Finder、Dock 和系统应用列表，包含标准与 Retina 尺寸。
- README 新增多设备事件流、设备筛选和原始 JSON 的实际界面截图。
- 图标随 App、DMG 和 ZIP 一起构建。截图使用独立开发测试端的虚构数据，正式应用仍不包含模拟设备或演示数据。

下载 `Tracking-Inspector-0.2.1-universal.dmg`，打开后将 `Tracking Inspector.app` 拖入 `Applications`。支持 Apple Silicon / Intel，要求 macOS 13+，无需 Python 或 Node.js。

此版本采用 ad-hoc 签名，尚未经过 Developer ID 签名与 Apple 公证。其他 Mac 下载后可能被 Gatekeeper 拦截。`SHA256SUMS` 提供安装包校验值。
