# Tracking Inspector v0.2.2

- 新增「手动连接」：填写手机的 IPv4 地址、端口和配对码，在 Bonjour 发现不可用但网络互通时连接设备。
- 保存、重新配对和移除手动地址；配对码仍只保存在进程内存中，所有连接合计最多 8 台。
- 将自动发现的连接标为「局域网」，避免将 USB 提供的网络通道误认为 Wi-Fi。
- 区分加密握手失败、端口拒绝、地址解析失败和超时，提供相应排查提示。

手机采集端需显示当前的 `IP:端口`；App 重启、无线重新开启或网络改变后应核对新地址与配对码。手动连接与自动发现使用相同 TLS 加密，无法绕过网络隔离。

DMG 支持 Apple Silicon 和 Intel。当前使用 ad-hoc 签名，尚未进行 Developer ID 签名和 Apple 公证。
